# CardPilot 应用图标

使用内置 imagegen 工具生成；原始成品保存在 `Brand/AppIcon.png`。`script/prepare_icons.sh` 仅缩放出 Asset Catalog 所需尺寸。

## 最终提示词

Use case: logo-brand. Asset type: production app icon for CardPilot, an elegant native iOS/macOS Hong Kong bank-card and cashback tracker. Create one original polished square app-icon artwork, 1024x1024. Subject: a sculptural ivory bank card silhouette merged with a precise upward-right compass/pilot arrow, a single strong memorable emblem, suggesting keeping spending on course. Style: premium Apple-platform icon craftsmanship, restrained layered depth with soft bevels and subtle light, simple geometry, crystal clear at 32px. Palette: deep petrol teal full-bleed background with gentle emerald illumination; ivory emblem with one small mint highlight. Composition: emblem centered, bold and generously padded, no outer device frame and no pre-rounded icon corners, artwork fills the entire square to all four edges. No words, letters, digits, currency symbols, bank logos, Mastercard circles, realistic card numbers, decorative sparkles, watermark, UI mockup, presentation board, or multiple variants. Opaque background, no transparency.
