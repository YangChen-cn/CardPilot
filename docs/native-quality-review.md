# 原生体验与产品质量精修

更新：2026-10-29。基于 `fd54829`，本轮围绕常用路径的操作可靠性、空状态和辅助功能调整，保持权益优先的轻量定位。

后续第二阶段（2026-10-30）：[Liquid Glass 与原生转场](liquid-glass-refinement.md)。下文保留第一阶段的实现与验证记录。

## 参考依据

- [Apple HIG：Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)：工具栏突出常用操作，低频操作集中在菜单中。账本操作由账本页面自己管理，避免顶层与子页面争用入口。
- [Apple HIG：Entering data](https://developer.apple.com/design/human-interface-guidelines/entering-data)、[Text fields](https://developer.apple.com/design/human-interface-guidelines/text-fields)：减少输入负担，使用合适键盘，明确日期、币种与错误。选填信息保持选填。
- [Apple HIG：Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets)：编辑流程有明确的取消与保存出口；本轮增加有修改时的放弃确认，避免误丢草稿。
- [Apple HIG：Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)、[设计提示](https://developer.apple.com/design/tips/)：适应大字号，保留文字层级，交互区域与可见图标区分考虑。布局不以缩小金额字体来解决拥挤。
- [Apple Wallet 交易详情](https://support.apple.com/en-us/104954)：卡片、交易列表和逐笔详情分层；CardPilot 沿用卡片进入账本的结构，保留原币与来源信息。
- [Mac 备忘录键盘快捷键](https://support.apple.com/en-kg/guide/notes/apd46c25187e/mac)：桌面常用操作可从键盘完成。本轮账本支持 ⌘N，编辑器支持 ⌘Return，设置使用原生 Settings 场景。

这些规范指导实现，不代表完成了设备上的视觉、VoiceOver 或全部 HIG 合规验收。

## 已完成的改进

| 路径 | 发现的问题 | 本轮处理 |
| --- | --- | --- |
| 交易、卡片、自定义活动、迎新编辑 | 取消会直接丢失已输入内容 | 对比草稿初始值；实际修改后取消或 Escape 需要确认放弃，阻止滑动误关；恢复原值后不多问一次 |
| 新增交易与活动 | 自动选择卡片容易被误判成用户修改 | 自动预选进入初始基线；切换字段、日期、图片或备注才算修改，草稿不提前写回持久化对象 |
| 快速记账 | 交易日期藏在更多选项；键盘完成操作仅控制金额框 | 日期移到基本资料，具体时间仍在选填区；金额、商户、汇率、备注共享焦点，完成按钮关闭当前输入键盘 |
| 记账错误反馈 | 保存错误位于表单底部，键盘或滚动可能遮住 | 错误置于顶部，配图标并发出辅助功能公告；疑似重复仍由用户决定是否另记一笔 |
| 归档卡交易 | 归档卡能打开新增表单但保存失败；编辑时改选卡片后原归档卡会从选项消失 | 详情禁用归档卡新增；交易编辑保留其原关联卡片，不以临时选择决定候选范围 |
| 大字号记账与账本 | 金额行横向拥挤，金额被缩小，商户过早截断 | 辅助功能字号下币种/金额纵排，交易金额左对齐，商户和金额允许自然换行；总览快捷操作改纵排 |
| 交易账本 | 顶层与账本分散管理操作，月份箭头的外部留白不等于按钮命中区 | 账本自己拥有新增和菜单；月份按钮弹性宽度，翻月按钮标签内提供 44×44 区域；干净空月份隐藏无意义筛选行 |
| 权益页 | 横排多个开关挤压内容；没有卡时缺少下一步 | 筛选统一收入菜单，保留当前筛选摘要；区分无卡、无收藏、无匹配和无当前权益，分别提供添加或清除入口 |
| 总览、选卡页 | 没卡也能进入无法保存的记账或无结果比较流程 | 无使用中卡片时直接提供资料库添加；总览移除不可用的记账快捷入口 |
| 迎新中心 | 默认空页只提示去另一个筛选，没有直接操作 | 直接进入可记录的迎新列表；完成和到账仍由用户手动记录 |
| macOS 设置 | 只有侧栏入口，缺少原生 App 菜单设置场景 | 增加 Settings 窗口，复用同一存储与同步、资料库环境；保留已有侧栏入口 |

## 架构与质量复核

- 保留五个 iPhone tab、三种卡包样式、macOS 侧栏和官方卡面的原始比例；不重写切卡动画。
- 卡片详情和权益展示继续与交易计算解耦；没有恢复自动迎新、回赠回放或精确结算。
- 账本继续使用限定月份/分页查询；macOS 单卡账本保留独立 Sheet 和 ScrollView，避免恢复曾经卡死的嵌套导航布局。
- 输入基线仅存在于编辑器生命周期，不新增 SwiftData 字段、同步格式或后台服务。个人账本、偏好与同步目录不重置。
- 系统背景、语义字体、深浅色资源和原生按钮样式继续复用。本轮没有改变卡面资产或通过自定义色块模拟系统工具栏。
- 没有做设备帧率或耗时采样，因此不宣称性能提升；本轮也没有扩大查询范围或新增交易计算链路。

## 用户验收重点

1. 在 macOS 账本使用 ⌘N 新增；交易、卡片、活动、迎新分别修改后取消，检查放弃/继续编辑；不修改或恢复原值应直接关闭。
2. 补记前一天消费，切换币种但不填汇率，确认仍可按原币保存；保存后检查对应卡片账本及月份。
3. 权益页切换收藏/卡片/已结束筛选，检查无结果时清除筛选；迎新空页进入可记录列表。
4. 从 App 菜单打开设置，核对它与侧栏设置显示同一配置。
5. 需要下一轮 iPhone 专项验收时，检查小屏、大字号、深色模式、键盘完成与滑动关闭草稿。VoiceOver 公告和实际触摸区域也需设备验收。

当前仍有其他独立设置/导入编辑器；本轮的草稿保护覆盖上述四类主编辑器，不将它描述为全 App 的自动保存。无障碍阅读顺序、颜色对比和实际交互是否顺手，也需要用户在设备上确认。
