## 软件更新

- 唯一更新源为 `https://api.github.com/repos/YangChen-cn/CardPilot/releases?per_page=100`，不使用 Catalog 作软件更新源。仅正式、非 Draft、数字版本 `vX.Y.Z`；分别寻找同一 tag 的 `CardPilot-X.Y.Z.dmg` / `.ipa`，不依赖 GitHub Latest 标记。其他仓库、错 tag／文件名、附带凭据／查询参数、零字节／超过512MiB的文件不接收。
- 自动检查默认开启，启动及回前台触发。成功缓存6小时并使用ETag，失败5分钟后可自动重试，手动检查不受间隔限制。只检查，不自动下载或安装；卡包内容中出现轻量提示，可暂时忽略该版本，设置始终可查看并重新检查。
- iOS 提供 IPA 下载链接。先显示更新前备份页，支持同步原账本并要求用户确认备份；下载后仍需侧载工具重新签名安装。
- macOS 在 App 内下载到专用缓存，支持进度、取消和失败重试；文件大小与 GitHub asset 的 `sha256:` digest 必须一致。缺少有效 digest 时改为发布页手动下载。完成后点击“安装并重启”，由独立CardPilotUpdater.app只读挂载DMG，核对Bundle ID、递增版本、最低系统、架构、代码签名和证书一致性，再暂存到原App同级目录。保存账本、正常退出后替换并自动重启；旧App在新版确认打开账本后才删除。不修改账本目录、稳定签名或钥匙串组件。
- 发布说明作为文本展示，不执行 HTML／脚本。演示／测试默认不联网，不伪造已发布版本。

下载使用 [URLSession](https://developer.apple.com/documentation/foundation/urlsession/download%28for%3Adelegate%3A%29)，校验数据来自 [GitHub release asset digest](https://docs.github.com/en/rest/releases/assets)。SHA-256 用于文件完整性，不等于 Apple 公证或独立发布者身份签名。

## iOS 删除与恢复

Apple 的[删除说明](https://support.apple.com/en-au/guide/iphone/iph248b543ca/27/ios/27)区分“删除 App”（移除 App 及本地数据）与“卸载 App / Offload”（保留文稿数据）。更新优先使用相同身份的侧载覆盖安装，仍建议先备份；不承诺更换 Bundle ID／签名工具或删除后会保留本地记录。

需要删除重装时：

1. 在有数据的设备设置 → 设备同步，选择 iCloud Drive 或其他真正的云盘文件夹，开启并执行立即同步。
2. 确认同步没有错误，再在系统“文件”或云盘中确认上传完成。App 的“上次同步”表示已向选定文件夹读写完成，不能证明云盘服务器已接收。“我的 iPhone”文件夹不是云端备份。
3. 邮件设置保存的服务网址与连接码随账本直接同步，无须另设密码；原有本机连接也会在同步时自动加入。
4. 重装后选择同一云端文件夹或已有 CardPilotSync，立即同步恢复银行卡、交易、账单、迎新及其他账本文档；邮件连接会自动恢复到此设备钥匙串。

本机显示偏好、自动检查开关、导入游标、通知授权及本机开关不随账本同步，各端独立设置。已发布旧安装包没有这些新入口，首次升级仍需使用其原有文件夹同步。

## 邮件连接直接同步（用户最新决定）

2026-11-03用户撤销此前恢复密码方案，要求完全移除额外密码。现无恢复密码输入、密钥派生或加解密流程。mailConnectionBackup版本2直接保存connection.url/token，随用户选择的私人文件夹同步。Mac/iOS本机仍用原钥匙串，不改变独立钥匙串组件或ACL。

保存连接时更新文档；文件夹同步先合并远端，再采用连接，防止旧设备拿旧连接覆盖新配置。已有本机连接且文档缺省时自动加入同步；普通重复同步不更新相同连接的修订时间。另一端同步后自动恢复，不要求重复填写连接码。主动断开仅让本设备忽略云端连接，可在邮件连接同步页重新启用。本机偏好、导入游标、通知授权仍独立。

旧版本1密文仅被动解码以免已有同步文件无法读取，没有解密入口；仍有本机连接的设备在同步时自动写入版本2。网址/连接码不写日志、不进Git仓库，只进入用户选定的私人账本文档。此决定取代此前密码方案。

## 验证边界

更新服务用本地URLProtocol响应验证缓存、版本/平台筛选、忽略与恢复、SHA-256和大小；邮件连接测试验证免密码保存、同步、幂等与临时模式不读真实凭据，不读写真实连接。界面、云盘实际上传、跨设备恢复、真实新版本下载/取消、自动替换/重启仍由用户确认；测试不替换用户当前安装。当前公开仓库没有高于0.2.0的正式安装包，不会为了验收发布假版本或替换用户的真实 App。

## macOS 安装助手边界

- 助手在主App的Contents/Helpers内嵌并用同一CardPilot证书签名，独立通过Launch Services启动，不继承主App沙盒、不注册常驻服务、不要求管理员权限。主App校验助手身份，助手校验指定PID仍运行的宿主位置、标识及同证书，下载和启动确认路径限定在宿主专用缓存UUID目录。
- 不只检查“签名有效”：新主App、更新助手、邮件钥匙串组件必须与原主App同叶证书，并保持各自标识；拒绝ad hoc、其他发布者、错误版本或其他App。只读挂载和签名工具均有超时，禁止交互式密码输入。
- 替换采用同级暂存/备份，移动失败恢复原位置；启动失败或新版未确认且已正常退出时恢复旧版。新版拒绝正常退出时保留备份并报错，绝不覆盖仍运行的bundle或强制结束进程。正常启动确认后才清理备份与本次DMG。
- 账本保存失败、同步或邮件导入未结束时不安装。安装确认提示用户先保存其他窗口的草稿。DMG/App Translocation/临时或不可写安装位置不强行覆盖，也不修改权限；需先将App移至可写目录。
- 更新回退只针对App bundle，不擅自还原数据库。后续存储迁移仍须遵守独立备份/可恢复策略，不能把安装助手当作数据迁移保障。本轮仍用SwiftData V3。
