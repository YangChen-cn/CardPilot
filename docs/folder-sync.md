# 手机与 Mac 同步

CardPilot 参考 YYReader 的文件夹同步方式。每端使用本机 SwiftData 账本，再把更改交给用户选择的云盘文件夹传输，不需要自建服务器、GitHub 账本仓库或 CloudKit 配置。

## 设置

1. 在 Mac 的「设置 → 设备同步」选择一个 iCloud 云盘文件夹，App 自动创建 `CardPilotSync/`。
2. 在 iPhone 同一位置选择同一个外层文件夹，或直接选择已有的 `CardPilotSync/`。两种选法都会使用同一个同步目录，不会形成 `CardPilotSync/CardPilotSync/`。
3. 两端开启「自动同步」。首次可以点「立即同步」，等待云盘传输后在另一端打开 App。

也可使用两端均可通过系统文件夹选择器访问的其他云盘。选择权限需在各设备分别授予；不能由 Mac 替手机选定文件夹。

同步包含卡片、卡面、活动规则、个人迎新日期、交易和删除操作。新设备会合并本机现有账本；新安装的空账本不会清空云端资料。演示模式和测试不连接个人同步目录。

本轮增加规则/价格历史、迎新到账、共享额度、双币账单、还款及待核对交易。同步格式升级到v2，新版兼容读取v1；手机和Mac均需更新，旧版会拒绝不支持的格式并保留本机账本。手改策略文档会覆盖空白模板，历史版本合并去重，重复同步不会反复覆盖再恢复同一设置。

本机编辑即时保存，通常延迟 1.5 秒发布到文件夹。前台每 12 秒检查，并在重新进入前台时同步；实际跨端延迟还取决于云盘上传和下载。iOS 后台不保证持续运行，打开 App 后继续。网络不可用时可以正常记账。

## 文件与冲突

目录内每台设备只写自己的 `<设备UUID>.json`，因此多台 Mac 或多部手机也不会争写同名文件。文件原子替换，未改变时不重写；请将这个包含个人消费的文件夹保存在自己的私有云盘中。

卡片、规则和交易逐条比较修改时间，较新的编辑胜出；同时间删除优先。不同记录的同时编辑会一起保留，同一交易的同时编辑不会逐字段组合。设备系统时间应保持自动校准。

官方目录卡片和规则使用稳定ID去重。个人尾号、账单/还款日、归档状态、卡面来源及自定义图片，以及迎新消费期与启用状态单独比较修改时间，避免新设备的空白目录模板盖掉个人设置；用户主动清空也会同步。删除会保留标记，防止旧快照恢复数据。个人资料时间戳相同时只比较对应的个人字段，不把公共资料字段混入比较，保证旧快照重放后仍收敛。

卡面来源明确记录为 `catalog` 或 `custom`，与自定义图片一同随卡片个人资料同步；本机 `cardArtwork` 文档只是持久化投影，不单独发布，避免来源与图片被不同快照分别覆盖。没有明确自定义标记的图片不视为个人卡面，官方卡始终读取当前 Catalog。编辑中选择「恢复官方卡面」后，预览立即切换，保存时清除自定义图；取消编辑不改变原卡。请将两端都更新到支持来源状态的版本。

文件无效、版本不支持、已发布文件暂时消失或文件夹不可访问时，保留本机账本并显示重试提示，不拿空资料覆盖它。重新选择外层或内层文件夹可恢复访问权限。

## 升级与验证

旧版账本会轻量迁移，首次磁盘升级前备份原数据库及关联文件到数据库旁的 `CardPilot Backups/Before Sync Upgrade/`。不会使用空内存账本代替加载失败的个人账本。

V3账户功能升级另在`CardPilot Backups/Before Account Upgrade V3/`保留升级前文件，原始备份不覆盖。

自动测试使用两个独立磁盘数据库和临时共享目录，覆盖双向增改删、图片、重复同步、目录选择、坏文件和旧版迁移。真实 iCloud 的手机/Mac 传输仍需在设备上人工确认；构建通过和本地往返测试不等同于跨设备验收。
