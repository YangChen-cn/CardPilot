# 自动记账、核对与账户管理

## Apple Pay

「记录银行卡消费」App Intent提供银行卡选择器，实体ID使用目录稳定ID或个人UUID，改名不会使工作流失效。原有按完整名称的工作流继续兼容。还支持交易时间、支付方式、分类、币种、汇率、交易地区和交易标识。交易地区可以选择香港（HK）、中国内地（CN）、澳门（MO）、其他地区或未指定，默认为未指定，请在自动化中选择实际地区；内地、澳门和其他地区会自动计作境外商户。地区独立于币种，地区信息可保存供用户自行参考，不用于自动判断银行最终资格。旧工作流的「境外商户」开关仍然有效。动作可在后台保存，不强制打开界面；Wallet触发和锁屏执行能力仍须手机实测。

交易标识在卡片范围去重；无标识但有稳定交易时间时使用卡片、商户、金额、币种、支付方式和毫秒时间指纹。同一来源的稳定时间指纹用于重试去重；跨来源即使时间相同也仅视为疑似。90秒内相似消费进入「交易核对」，不直接作为第二笔入账；用户可确认其为另一笔真实交易或忽略。请优先绑定Wallet提供的原始交易时间及标识，勿在每次重试时重新生成它们。

自动化运行后的资料先保存在手机，文件夹同步在App前台继续。工作流不能绕过系统的Wallet卡片选择及自动运行权限。

## 手动记账

手动记录与自动记账、CSV 共用检测服务。疑似重复时先确认“保存为另一笔消费”，确认前不写入账本或核对列表；取消保留原记录。编辑交易排除自身，保留原来源身份。只记住成功保存的卡片、分类和支付方式，不记住金额与商户；演示模式不修改个人偏好。

## CSV及未来银行适配器

「设置 → 导入消费记录」选择所属卡片并上传UTF-8文件，预览后整批保存。无效批次回滚，明确重复跳过，疑似重复进入核对。

最小格式：

```csv
id,merchant,date,amount,currency,payment
bank-reference-001,"Cafe, Central",2026-10-20T04:30:00Z,120.50,HKD,Apple Pay
```

必需列：merchant、date、amount。支持额外的card_id、currency、hkd_rate、category、payment、channel、overseas、region、id。日期可用ISO8601或YYYY-MM-DD；只有日期而无时间时不能视为稳定交易时间。文件最大5MB、10,000行，金额正数，退款先核对原记录。导出包含稳定card_id及交易id，可重复导入而不重复记账。

无银行ID的CSV行采用文件和行号生成重试身份；同值多行各自保留核对机会，日期型记录按香港同一日匹配疑似交易。

region列接受HK、CN、MO、other或空值；CN、MO和other会自动标记境外，空值保留为未知地区，不会按币种猜测地区。

银行原始文件尚未逐一适配。`TransactionImportAdapter`统一输出`TransactionRequest`，新增银行CSV或邮件解析器后继续走相同校验、预览及去重服务，无需另写账本保存逻辑。

## 额度与还款

在「额度与还款」将同一银行共用信用额度的卡片加入同一个HKD等值额度组，录入各卡HKD/CNY/USD账单。账单总额可包含上期欠款；可用额度仅使用每卡每币种最新账单，再加账单截止日后消费、减之后还款，旧账单不重复相加。外币账单使用录入时的汇率快照。

部分还款分笔保存，可撤销；金额不能超过该账单已记录的未还金额。还款只减少欠款，不计消费或迎新进度。没有完整账单、还款及消费记录时，可用额度只是估算，不是银行实时额度。选卡建议不模拟可用额度或银行结算。

## 迎新与提醒

个人迎新状态独立于账本：未确认、进行中、用户确认已达标、奖励已到账、已结束。用户填写个人日期、门槛参考、奖励内容和备注；不再逐笔计算合资格消费。到期提醒只针对已记录真实截止日期的进行中迎新，默认不申请通知权限。

支付方式、地区、渠道、汇率均为选填。缺失它们不会进入人工核对；无法匹配卡片、金额/币种错误、疑似重复或财务冲突仍需核对。没有可信汇率的外币记录直接原币入账，港币合计仅包含可换算记录；CSV缺失汇率和Shortcuts汇率0均保留未知，不默认为1。

macOS单卡账本用独立CardLedgerSheet隔离导航搜索栏/工具栏，内部使用ScrollView/LazyVStack；iOS保留List与推入导航。已删除活动计算快照、返现资格确认及TransactionPaymentUpdater，不要重新引入。
