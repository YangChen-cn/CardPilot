# 轻量体验收口（2026-10-29）

以 iPhone 为优先平台，保留五个 tab、卡面／紧凑／叠放三种样式与原切卡状态机。macOS 保留侧栏及独立单卡账本 Sheet。

## 当前行为

- 目录加载统一比较内置与有效缓存版本；旧缓存和同版本异内容不能覆盖更新内置快照，不发送其条件请求头。添加流程在目录变化后刷新可见列表，个人配置期间不打断。
- 当前权益继续排除归档卡。迎新历史明确请求归档资料，仅保留有个人记录的迎新；损坏的已有记录仍保留可见入口。默认“我在追踪”，未确认方案在“可记录”中，不制造未完成任务。
- 卡面下可直接进入单卡账本。权益支持按卡片筛选，显示筛选状态；收藏及重点限制沿用现有权益模型，结束活动可展开查看。
- 金额旁直接切换币种；地区、汇率和渠道仍为选填。新建聚焦金额、可收起键盘，成功保存后反馈卡片及原币金额；不沿用上一笔金额或商户。
- 账本默认香港记账时区的本月，可切换月份。普通查询先按月份、卡片及分类限范围；“全部历史”明确选择，搜索按200行扫描、100个命中分页，批次之间让出主线程，旧异步结果不能覆盖新条件。跨月结果只标已加载数量，不用部分金额伪装全量合计。
- 账本显示全局待核对入口及邮件导入状态，复用现有核对和设置页面。无可信汇率时保留原币，不突出误导性的HK$0。
- 选卡输入直接展示类别、地区及支付方式；手机候选先展示一项主要权益，其余可展开。没有恢复收益计算或自动资格判断。
- 到期提醒仅针对用户主动追踪且截止日明确的迎新；显示实际系统通知权限并支持关闭，关闭会移除已有相关提醒。

## 验证与验收

目录与归档历史边界由 RemoteCatalogTests 覆盖；LedgerQueryTests 覆盖月份、跨年、卡片／分类、跨月分页、稀疏搜索和1k／10k隔离基准。基准只验证数据查询，不代表真实设备滚动或动画验收。UI由用户手动验收；不以编译、进程启动替代视觉验证。

不改SwiftData Schema、文件夹同步格式、真实账本或邮件钥匙串组件。没有新增活动进度、精确回赠结算、预算或服务器。实际运行结果持续记录在本地项目交接文档。
